# Modelo econômico — hipóteses, não resultados

- Receita de serviço = número de fretes intermediados × comissão/taxa acordada.
- Margem de contribuição = receitas de serviço − despesas variáveis e tributos incidentes.
- Resultado operacional = margem de contribuição total − custos fixos.
- Capital de giro = saídas previstas até os recebimentos correspondentes.

## Dados necessários
Preço aceito pelo cliente, prazo de recebimento, tributos, seguros, custo documental, custo operacional, inadimplência e comissões efetivas.

Nenhum resultado histórico, projeção de lucro ou promessa de retorno é apresentado aqui. Validar cenários conservador, base e otimista a partir de dados reais.
